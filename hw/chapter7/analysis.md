## Q4 SJF 与 FIFO 何时有相同周转时间

### 预测与理由

在本模拟器的同时到达、纯 CPU 假设下，FIFO 输入顺序按长度非递减排列时，两者顺序一致，逐作业与平均周转时间均相同；等长作业和单个作业为特例。同长度保持原输入顺序。Q1、Q2 为正例。反例 300,200,100：FIFO 平均周转为 1400/3=466.67，SJF 为 1000/3=333.33。长作业排在前面使短作业等待，体现车队效应。交换相邻长作业 a 和短作业 b（a>b），先执行 b 会使完成时间之和减少 a-b，因此存在严格逆序时 FIFO 的平均周转严格大于 SJF。

## Q5 SJF 与 RR 何时有相同响应时间

### 预测与理由

可保证逐作业响应相同的条件：RR 初始队列已按长度升序排列，前 N-1 个作业各能在一个时间片内完成，即 q>=max(L0,...,L[N-2])。最后一个作业可以长于 q，因为它之后没有尚未响应的作业。更强、更易记的充分条件为 q>=max(L)。单作业响应始终为 0；等长多作业在 q>=L 时相同。用 2,4,6 验证：SJF 响应向量 (0,2,6)，RR q=4 与 q=6 都相同，q=1 为 (0,1,2)。仅增大时间片还不够：6,2,4 的 RR q=6 退化为 FIFO，响应 (0,6,8)，而 SJF 按 J1,J2,J0 执行，按编号记录响应 (6,0,2)。此处比较逐作业响应，不把平均值偶合当成调度相同。

## Q6 SJF 响应时间随作业长度的变化

## Q7 RR 时间片与最坏响应时间

### 预测与理由

N 个正长度作业在 t=0 同时到达，队列顺序固定、切换免费时，第 k 个作业（从 0 编号）响应 Rk=sum(min(q,Lj), j<k)。所以 Rmax=sum(min(q,Lj), j=0..N-2)<=(N-1)q，前 N-1 个作业长度至少为 q 时取等号。最坏单作业响应与平均响应不同；所有作业都至少长 q 时，平均响应为 (N-1)q/2。对三个长度 200 的作业，q=1,5,10,50,200,300 的平均响应为 1,5,10,50,200,200，最大响应为 2,10,20,100,400,400。固定负载下响应随 q 非递减，达到每个作业一片完成后饱和为 FIFO，不会无限线性增长。若换入下一作业成本 c、首次派发免费，上界为 (N-1)(q+c)；本模拟器不计该成本。
