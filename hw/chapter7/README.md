## 结果概述

| 问题 | 主要结果 |
|---|---|
| Q1 | 200,200,200：FIFO/SJF 平均响应 200，平均周转 400 |
| Q2 | 100,200,300：FIFO/SJF 平均响应 133.33，平均周转 333.33 |
| Q3 | RR q=1 平均响应都为 1；两种负载平均周转为 599、465.67 |
| Q4 | 输入升序时 FIFO 与 SJF 相同；逆序输入体现车队效应 |
| Q5 | 初始升序且前 N-1 个作业各能一片完成，可得到相同逐作业响应 |
| Q6 | SJF 全部长度等比例增长，响应时间等比例增长 |
| Q7 | RR 最坏响应不超过 (N-1)q；固定负载下增大 q 后最终饱和为 FIFO |

## 方法与范围

采用先预测、后验证：先保存全部推导及 23 组预测，再运行 `-c`。逐作业响应、周转、等待时间及平均值全部核对一致，预测保持不变。全部实验同时到达、只用 CPU，不计算上下文切换成本。
